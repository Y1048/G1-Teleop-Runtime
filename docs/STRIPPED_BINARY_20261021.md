# C++ 실행파일 심볼 제거 검증 — 2026-10-21

기존 G1 설치를 변경하지 않고 배포 복사본에 LLVM 18.0.3 `llvm-strip --strip-all`을 적용했습니다.

- 실행파일: 4,186,424 → 2,270,184 bytes.
- 제거: `.symtab`, `.strtab`, `.comment`. 실행에 필요한 `.dynsym`, `.dynstr`는 보존.
- 모든 프로그램 헤더 동일. PT_LOAD는 ELF의 section table 위치/개수 필드만 제외하고 바이트 동일.
- 실행 코드, 상수/데이터, 동적 심볼·재배치·예외 처리 등 SHF_ALLOC 섹션 26개 바이트/실행 관련 메타데이터 동일.
- 시작 스크립트는 실행파일 SHA-256 리터럴만 갱신. 모터 옵션·제어 로직·정책·gain은 불변.
- 원본 G1 파일 10,318개 해시 재검사: 불일치 0개.

## 실제 실행한 검사

1. PC: ELF 비교 통과. 명령어·엔트리포인트·machine 필드 변조 3가지가 모두 거부되는지 확인.
2. PC: 기존 테스트 31개 중 29개 통과, POSIX 전용 2개 Windows에서 skip. 동일 테스트를 G1 Python 3.8에서 실행해 31/31 통과.
3. G1: 네트워크·장치가 격리된 namespace에서 ELF loader `--list` 비교. 두 실행파일 모두 exit 0, 해결된 라이브러리 목록 동일. application main은 실행하지 않음.
4. G1: 별도 복사본에서 actuator를 제거한 server/IK/heading 시작·ACK·Enter 종료. Valleg는 idle fixture. 31.53초, exit 0, ready/ACK 및 `all stopped` 확인, 검사 도구 강제 종료 없음. 원래 종료 스크립트의 SIGTERM/KILL fallback이 없는 뜻은 아님.
5. 패키지 manifest 10,318개 및 원본과의 변경 범위를 대조. payload에서는 실행파일과 시작 스크립트 두 파일만 변경.

SSH가 중간에 끊겼지만 재접속해 검사 완료 로그를 회수했습니다. 격리 환경의 LowState SSH 연결 오류는 실제 장치·네트워크를 차단했기 때문이며, 실제 LowState 정상 수신으로 해석하지 않습니다.

## 한계

이 검사는 심볼 제거로 실행 코드·로딩이 바뀌지 않았다는 근거입니다. 정책 추론·실제 모터·Quest 통합 재시험이나 모든 동작의 동일성 보장은 아닙니다. 문자열과 필수 동적 심볼은 남으므로 역공학 불가능을 뜻하지 않습니다.

이전 정적 심볼 포함 실행 패키지는 공개 Release에서 내리고 원본은 로컬 복구본으로 보관합니다. v0.1.0의 태그·문서·외부 라이브러리 자료·APK는 남습니다. 예전 설치 스크립트의 다운로드는 실패할 수 있으므로 최신 main의 설치기를 사용하세요. 이전 G1 설치 파일을 자동 덮어쓰지는 않습니다.

현재 공개 README는 비공개 개발 저장소 링크 없이 APK 파일명·SHA-256으로 식별합니다. 이전 Git 이력의 문구를 지우는 history rewrite는 하지 않았습니다.
