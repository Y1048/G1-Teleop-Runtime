# 전달 시 라이선스 상태

공동 작성자·소속기관의 허용 범위는 2026-10-20 사용자 확인 완료입니다.
공개 배포 심사를 추가로 확대하지 않고 실제 전달물에 필요한 고지와 외부 구성요소 조건을 유지합니다.

핵심 C++ 소스는 제공 대상이 아닙니다. 이 저장소는 제3자 구성요소에 대한 추가 권한을 부여하지 않습니다.
NVIDIA 모델, Unitree SDK, DDS, Python 및 네이티브 의존성의 기존 라이선스는 각각 적용됩니다.
원본 패키지의 notices와 준비된 source/build 보완 자료는 실행 패키지와 함께 제공할 예정입니다.
일부 네이티브 라이브러리의 정확한 대응 소스·빌드 정보는 아직 완전히 확정되지 않았습니다.
따라서 현 단계에서 모든 제3자 조건이 충족됐다고 표시하지 않습니다.

이 저장소에 아직 없는 라이선스 보완 아카이브를 제공 완료로 간주하지 마세요.
코드에 일괄 오픈소스 라이선스를 지정하지 않았습니다. 공개 열람은 무제한 재사용 허락과 다릅니다.
